# Production control room

Prepared by **Tahah**.

An interactive production-technology workflow — **Screen › Diagnose › Evaluate › Register** —
built as a static site on real field data (Equinor Volve) and a synthetic 40-well field.

**Live:** https://monkeheim-prime.github.io/production-control-room/

| Stage | What it does |
|---|---|
| 1 Screen | Data QA/QC, heterogeneity index, Pareto of gap to potential, water cut vs GOR, map. One set of well dots morphs between views and plays through time. |
| 2 Diagnose producer | Linked history lanes (rates, pressures, choke, events) with brush-zoom and replay, Chan WOR diagnostic, PI trend, nodal potential, illustrative completion schematic, rule-based mechanism scoring, data gaps → well test plan. |
| 2b Diagnose injector | Modified Hall plot (integral + derivative), rate-based connectivity, voidage replacement. |
| 3 Evaluate | Risked gain waterfall, opportunity bubble map, efficient frontier, NPV/payback, budget- and rig-constrained portfolio optimiser. |
| 4 Register | Stage-gate funnel, editable opportunity register (CSV export), lookback, schedule, printable well one-pager, full-screen review-meeting mode. |

Supporting toolkit:

| Module | What it does |
|---|---|
| T1 Decline & forecast | Arps decline fits with P10/P50/P90 bands, a hide-the-last-N-months backtest, and a field-wide backtest scoreboard. |
| T2 Nodal analysis | IPR (PI + Vogel) against a simplified multiphase VLP, operating point and tubing sensitivity, model-vs-measured BHP check. |
| T3 Gas lift allocation | Equal-slope allocation of limited lift gas across the Field X gas-lift wells, compared with current and equal-split allocations. |
| T4 CO₂ & geothermal | Illustrative CO₂ injection well (Peng–Robinson, phase envelope, Joule–Thomson cooling, hydrate risk) and a geothermal producer with lithium co-production. |
| T5 Wax & hydrates | Flowing temperature along the tubing and flowline against the wax appearance temperature and the hydrate curve, with inhibitor dosing. |
| T6 Artificial lift | Lift-method screening radar, ESP design with a VSD frequency envelope, and rod-pump dynamometer cards (synthetic) with a rule-based classifier. |
| T7 Network | Wells → manifolds → separator → export/water treatment, with facility constraints, choke-back allocation and a debottleneck what-if. |
| T8 Event detection | Real Petrobras 3W well instances with expert labels, replayed through a causal EWMA/CUSUM and oscillation detector, scored openly. |

The **Methods** drawer on every page lists the equations, rules and assumptions.

## Data

| Dataset | Nature | Source / licence |
|---|---|---|
| Volve | Real daily production 2007–2016, 5 producers + 2 injectors | Equinor and the Volve licence partners, [Equinor Open Data Licence](https://www.equinor.com/energy/volve-data-sharing). Derived JSON stays under that licence. |
| Petrobras 3W | Real offshore well sensor data (8 instances, 15-s means) with expert event labels | [petrobras/3W](https://github.com/petrobras/3W), CC BY 4.0. Vargas et al. (2019), J. Pet. Sci. Eng. 181, 106223. Prepared by `pipeline/threew.py`. |
| Field X | **Synthetic**, 34 producers + 6 injectors, monthly 2012–2025 | Generated by `pipeline/fieldx.py` (seed 42). Each well has a hidden true mechanism used to score the diagnosis (33/34 producers, 6/6 injectors). |

Not in the public Volve file, and therefore assumed or illustrative in the UI: reservoir pressure,
completion details, lift type, injection pressure. Engineering correlations are implemented from the
original papers (Chan 1995; Izgec & Kabir 2009; Hall 1963).

## Structure

| Path | Purpose |
|---|---|
| `site/` | Vite + TypeScript + D3 front end (`src/analysis` = engine, `src/views` = pages) |
| `pipeline/volve.py` | Cleans the Volve workbook and runs QA/QC → `site/public/data/volve.json` |
| `pipeline/fieldx.py` | Generates Field X → `site/public/data/fieldx.json` |
| `pipeline/threew.py` | Prepares real Petrobras 3W instances → `site/public/data/3w.json` |
| `data/raw/` | Downloaded source data (git-ignored) |

## Rebuild the data

```sh
python3 -m venv .venv && .venv/bin/pip install pandas==2.2.3 openpyxl==3.1.5 numpy
mkdir -p data/raw/volve
curl -L -o data/raw/volve/mehrdad.xlsx "https://raw.githubusercontent.com/mehrdadamini/Volve-production-data/HEAD/Volve%20production%20data.xlsx"
.venv/bin/python pipeline/volve.py
.venv/bin/python pipeline/fieldx.py
# 3W event-detection data: see the download loop at the top of pipeline/threew.py, then
.venv/bin/pip install pyarrow==17.0.0 && .venv/bin/python -I pipeline/threew.py
```

## Develop

```sh
cd site && npm install && npm run dev
```

Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.
